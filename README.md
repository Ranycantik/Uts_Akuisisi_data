# UTS Akuisisi Data

Akuisisi dan penggabungan data wisatawan nusantara (BPS 2022-2025),
data cuaca (Open-Meteo), dan tabel ibu kota provinsi (Wikipedia).

## Isi repository
- `Uts_Akuisisi_(2)_(1).ipynb`: notebook alur akuisisi
- `hasil_uts_dam (3)/data/raw`: data mentah
- `hasil_uts_dam (3)/data/processed`: hasil penggabungan
- `hasil_uts_dam (3)/docs`: Data Ethics Checklist, provenance, bukti lisensi
